趣味 AI 项目

今天的共同主题：让一群 AI 先吵起来，再看它们能不能吵出更好的答案。

PROJECT — 01

AI Conference Room — 两个 AI 在一个房间里当面谈判

两个人各把自己的 AI 助手放进同一个房间 ID，两个助手各凭自己机器上的文件、日志与约束对话，彼此看不到对方的资料；你可以打开链接实时围观，最后由双方投票达成结论才算谈完。页面上的实例：一支支付团队的助手与一支移动端团队的助手，商量一个旧 API 到底何时能下线。好玩点：分歧是真的——因为双方掌握的信息本来就不一样。

getaiconferenceroom.com
PROJECT — 02

The AI Counsel — 把问题交给一个“AI 议会”

源自 Andrej Karpathy 的 LLM Council 思路：一个问题同时发给多个模型，模型们匿名互评、为排名辩护，最后由一位“主席”模型综合成最终答案。作者实测：4 个模型、2 个问题就烧了约 71 万 token，不适合日常使用，适合高风险决策前的“找盲点”。开源，可本地跑。

MakeUseOf 介绍（2026-11-20） GitHub 仓库
PROJECT — 03

Assembly — 多智能体“辩论工作室”

实验性开源项目：Solver、Researcher、Critic、Planner、Synthesizer 等角色先独立解题，再对比立场与证据，分歧大时触发研究或辩论，最后合成的答案会明确标出尚未解决的不确定性；可自选 3 / 5 / 10 / 15 分钟时间预算，自带 API key（BYOK）。作者明确提醒：这只是工程实验，尚未证明能提高答案准确率。
